LITURGY LAB — VIEWER AND RESEARCH PACKAGE

Extract the entire ZIP. On Mac double-click Start Viewer.command; on Windows
double-click Start Viewer.cmd. Or run python3 run_viewer.py, then open
http://127.0.0.1:8766/. No packages or model downloads are needed for viewing.
Keep the terminal open. Control-C stops the viewer.

YouTube playback requires internet. The recordings are not bundled.
Open reports/ for findings and help. The research/ folder contains the pipeline,
tests, and saved experiment outputs; see its README for inference setup.

The ZIP matches the GitHub repository except for the original Word specification
in private/, which is ZIP-only. Never upload private/ to GitHub.
Models, recordings, environments, caches, and private reviews are excluded.
See README.md for details and PUBLISH-GITHUB-PAGES.txt for hosting.
