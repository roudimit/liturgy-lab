GITHUB PAGES

The public package is already hosted at https://roudimit.github.io/liturgy-lab/.
Use main and /(root) under repository Settings > Pages.
Pushes to main trigger deployment. Check the Actions tab for Pages deployment.

When uploading an extracted ZIP, exclude private/ and the original Word document.
Keep index.html, assets/, reports/, and all other public package files at the
repository root. No server, API key, or model installation is required.
